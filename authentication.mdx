## Introducción

LatePoint API Extension utiliza un sistema de autenticación basado en **API Keys** para garantizar la seguridad de tus datos. Cada solicitud a la API debe incluir una clave válida para ser procesada.

## Generación de API Keys

### Crear una Nueva API Key

1. Accede a **LatePoint > API Settings** en tu panel de WordPress
2. Haz clic en **"Generate New API Key"**
3. Asigna un nombre descriptivo (ej: "App Móvil", "Sistema CRM")
4. Configura los permisos necesarios
5. Copia y guarda la clave generada de forma segura

<Warning>
  **Importante**: La API Key solo se muestra una vez. Si la pierdes, deberás generar una nueva.
</Warning>

### Configuración de Permisos

Cada API Key puede tener permisos específicos para diferentes recursos:

## Uso de la API Key

### Header de Autenticación

Incluye tu API Key en el header `X-API-Key` de cada solicitud:

<CodeGroup>

```bash cURL
curl -X GET "https://tu-sitio.com/wp-json/latepoint/v1/bookings" \
  -H "X-API-Key: lp_live_1234567890abcdef" \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const apiKey = 'lp_live_1234567890abcdef';

const response = await fetch('https://tu-sitio.com/wp-json/latepoint/v1/bookings', {
  method: 'GET',
  headers: {
    'X-API-Key': apiKey,
    'Content-Type': 'application/json'
  }
});
```

```python Python
import requests

api_key = 'lp_live_1234567890abcdef'
headers = {
    'X-API-Key': api_key,
    'Content-Type': 'application/json'
}

response = requests.get(
    'https://tu-sitio.com/wp-json/latepoint/v1/bookings',
    headers=headers
)
```

```php PHP
<?php
$apiKey = 'lp_live_1234567890abcdef';
$headers = [
    'X-API-Key: ' . $apiKey,
    'Content-Type: application/json'
];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, 'https://tu-sitio.com/wp-json/latepoint/v1/bookings');
curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

$response = curl_exec($ch);
curl_close($ch);
?>
```

</CodeGroup>

## Tipos de API Keys

### Claves de Desarrollo (Test)

Para desarrollo y pruebas, utiliza claves que comienzan con `lp_test_`:

```
lp_test_1234567890abcdef
```

**Características:**
- Solo funcionan en entornos de desarrollo
- Datos limitados o simulados
- Rate limiting más permisivo

### Claves de Producción (Live)

Para entornos de producción, utiliza claves que comienzan con `lp_live_`:

```
lp_live_1234567890abcdef
```

**Características:**
- Acceso completo a datos reales
- Rate limiting estricto
- Logs de auditoría completos

## Seguridad y Mejores Prácticas

### Almacenamiento Seguro

<Tip>
  **Nunca** hardcodees las API Keys en tu código fuente. Utiliza variables de entorno.
</Tip>

**✅ Correcto:**
```javascript
const apiKey = process.env.LATEPOINT_API_KEY;
```

**❌ Incorrecto:**
```javascript
const apiKey = 'lp_live_1234567890abcdef'; // ¡Nunca hagas esto!
```

### Variables de Entorno

Configura tus API Keys como variables de entorno:

```bash .env
LATEPOINT_API_KEY=lp_live_1234567890abcdef
LATEPOINT_BASE_URL=https://tu-sitio.com/wp-json/latepoint/v1
```

### Rotación de Claves

1. **Genera una nueva API Key** antes de que expire la actual
2. **Actualiza tu aplicación** con la nueva clave
3. **Prueba** que todo funcione correctamente
4. **Revoca la clave anterior** una vez confirmado el cambio

### Monitoreo y Logs

LatePoint API Extension registra automáticamente:

- Todas las solicitudes autenticadas
- Intentos de acceso no autorizados
- Uso por API Key
- Errores de autenticación

Accede a los logs en **LatePoint > API Settings > Activity Logs**.

## Rate Limiting

### Límites por Defecto

| Tipo de Clave | Solicitudes por Minuto | Solicitudes por Hora |
|---------------|------------------------|----------------------|
| Test          | 100                    | 1,000                |
| Live          | 60                     | 3,600                |

### Headers de Rate Limiting

Cada respuesta incluye información sobre tu uso actual:

```http
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 45
X-RateLimit-Reset: 1640995200
```

### Manejo de Límites Excedidos

Cuando excedas el límite, recibirás una respuesta `429 Too Many Requests`:

```json
{
  "error": {
    "code": "rate_limit_exceeded",
    "message": "Rate limit exceeded. Try again in 60 seconds.",
    "retry_after": 60
  }
}
```

## Errores de Autenticación

### 401 Unauthorized

**Causa:** API Key faltante o inválida

```json
{
  "error": {
    "code": "unauthorized",
    "message": "Invalid or missing API key"
  }
}
```

**Solución:**
- Verifica que incluyes el header `X-API-Key`
- Confirma que la API Key sea correcta
- Asegúrate de que la clave no haya expirado

### 403 Forbidden

**Causa:** API Key válida pero sin permisos suficientes

```json
{
  "error": {
    "code": "forbidden",
    "message": "Insufficient permissions for this endpoint"
  }
}
```

**Solución:**
- Revisa los permisos de tu API Key
- Contacta al administrador para ampliar permisos

## Gestión de API Keys

### Listar Claves Activas

En **LatePoint > API Settings**, puedes ver:

- Todas las API Keys generadas
- Fecha de creación y último uso
- Permisos asignados
- Estado (activa/inactiva)

### Revocar una API Key

1. Ve a **LatePoint > API Settings**
2. Encuentra la clave que deseas revocar
3. Haz clic en **"Revoke"**
4. Confirma la acción

<Warning>
  Una vez revocada, la API Key dejará de funcionar inmediatamente en todas las aplicaciones que la utilicen.
</Warning>
