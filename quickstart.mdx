## Instalación

<Steps>
  <Step title="Descargar el Plugin">
    Descarga el archivo ZIP del plugin LatePoint API Extension desde tu cuenta de LatePoint o desde el repositorio autorizado.
  </Step>
  
  <Step title="Instalar en WordPress">
    1. Ve a **Plugins > Añadir nuevo** en tu panel de WordPress
    2. Haz clic en **Subir plugin**
    3. Selecciona el archivo ZIP descargado
    4. Haz clic en **Instalar ahora**
    5. **Activa** el plugin una vez instalado
  </Step>
  
  <Step title="Verificar Requisitos">
    Asegúrate de que tienes:
    - LatePoint plugin principal instalado y activado
    - WordPress 5.0 o superior
    - PHP 7.4 o superior
    - Permisos de administrador en WordPress
  </Step>
</Steps>

## Configuración Inicial

### 1. Acceder a la Configuración

Una vez activado el plugin, encontrarás la nueva sección **API Settings** en el menú de LatePoint:

```
LatePoint > API Settings
```

### 2. Generar tu API Key

<Warning>
  Guarda tu API Key en un lugar seguro. No podrás verla nuevamente una vez generada.
</Warning>

1. En la página de configuración de API, haz clic en **"Generate New API Key"**
2. Copia la API Key generada
3. Guárdala en tu gestor de contraseñas o archivo de configuración seguro

### 3. Configurar Permisos

Configura qué endpoints estarán disponibles para tu API Key:

- ✅ **Bookings**: Gestión completa de reservas
- ✅ **Customers**: Administración de clientes
- ✅ **Agents**: Consulta de agentes
- ✅ **Services**: Consulta de servicios
- ✅ **Availability**: Verificación de disponibilidad

## Tu Primera Llamada a la API

### Endpoint Base

Todas las llamadas a la API utilizan la siguiente URL base:

```
https://tu-sitio.com/wp-json/latepoint/v1/
```

### Autenticación

Incluye tu API Key en el header de cada solicitud:

```bash
X-API-Key: tu_api_key_aqui
```

### Ejemplo: Obtener Lista de Servicios

<CodeGroup>

```bash cURL
curl -X GET "https://tu-sitio.com/wp-json/latepoint/v1/services" \
  -H "X-API-Key: tu_api_key_aqui" \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch('https://tu-sitio.com/wp-json/latepoint/v1/services', {
  method: 'GET',
  headers: {
    'X-API-Key': 'tu_api_key_aqui',
    'Content-Type': 'application/json'
  }
});

const services = await response.json();
console.log(services);
```

```python Python
import requests

url = "https://tu-sitio.com/wp-json/latepoint/v1/services"
headers = {
    "X-API-Key": "tu_api_key_aqui",
    "Content-Type": "application/json"
}

response = requests.get(url, headers=headers)
services = response.json()
print(services)
```

```php PHP
<?php
$url = 'https://tu-sitio.com/wp-json/latepoint/v1/services';
$headers = [
    'X-API-Key: tu_api_key_aqui',
    'Content-Type: application/json'
];

$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, $url);
curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);

$response = curl_exec($ch);
$services = json_decode($response, true);
curl_close($ch);

print_r($services);
?>
```

</CodeGroup>

## Verificar la Configuración

### Test de Conectividad

Puedes verificar que todo funciona correctamente con este endpoint de prueba:

```bash
curl -X GET "https://tu-sitio.com/wp-json/latepoint/v1/status" \
  -H "X-API-Key: tu_api_key_aqui"
```

**Respuesta exitosa:**
```json
{
  "status": "success",
  "message": "API is working correctly",
  "version": "1.0.0",
  "timestamp": "2024-01-15T10:30:00Z"
}
```

## Solución de Problemas

<AccordionGroup>
  <Accordion title="Error 401: Unauthorized">
    - Verifica que tu API Key sea correcta
    - Asegúrate de incluir el header `X-API-Key`
    - Confirma que la API Key no haya expirado
  </Accordion>
  
  <Accordion title="Error 404: Not Found">
    - Verifica que la URL base sea correcta
    - Confirma que el plugin esté activado
    - Revisa que los permalinks estén configurados correctamente
  </Accordion>
  
  <Accordion title="Error 500: Internal Server Error">
    - Revisa los logs de WordPress
    - Verifica que LatePoint principal esté instalado
    - Confirma que los requisitos del sistema se cumplan
  </Accordion>
</AccordionGroup>
