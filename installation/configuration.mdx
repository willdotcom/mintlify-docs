## Configuración Inicial

### Acceso a la Configuración

Después de activar el plugin, accede a la configuración:

1. Ve a **LatePoint > API Settings** en tu panel de WordPress
2. Verás el panel de configuración de la API
3. Si es la primera vez, se ejecutará el asistente de configuración

### Panel de Configuración

El panel principal incluye las siguientes secciones:

<AccordionGroup>
  <Accordion title="General Settings">
    - Estado de la API (Activada/Desactivada)
    - URL base de la API
    - Versión actual del plugin
    - Información de licencia
  </Accordion>
  
  <Accordion title="API Keys Management">
    - Lista de API Keys activas
    - Generación de nuevas claves
    - Configuración de permisos
    - Revocación de claves
  </Accordion>
  
  <Accordion title="Security Settings">
    - Rate limiting
    - Restricciones de IP
    - Configuración de CORS
    - Logs de auditoría
  </Accordion>
  
  <Accordion title="System Status">
    - Verificación de requisitos
    - Estado de la base de datos
    - Información del servidor
    - Diagnósticos
  </Accordion>
</AccordionGroup>

## Configuración de Seguridad

### Rate Limiting

Configura límites de solicitudes para proteger tu servidor:

```json
{
  "requests_per_minute": 60,
  "requests_per_hour": 3600,
  "requests_per_day": 86400,
  "burst_limit": 10
}
```

**Configuración recomendada por tipo de uso:**

| Tipo de Aplicación | Por Minuto | Por Hora | Por Día |
|-------------------|------------|----------|---------|
| Aplicación Móvil  | 30         | 1800     | 43200   |
| Sitio Web         | 60         | 3600     | 86400   |
| Sistema Interno   | 120        | 7200     | 172800  |
| Integración CRM   | 20         | 1200     | 28800   |

### Restricciones de IP

Para mayor seguridad, puedes restringir el acceso por IP:

<Tabs>
  <Tab title="Whitelist">
    ```
    # Permitir solo estas IPs
    192.168.1.100
    10.0.0.0/8
    203.0.113.0/24
    ```
  </Tab>
  
  <Tab title="Blacklist">
    ```
    # Bloquear estas IPs
    192.168.1.50
    172.16.0.0/12
    198.51.100.0/24
    ```
  </Tab>
</Tabs>

### Configuración CORS

Para aplicaciones web que consuman la API desde el navegador:

```json
{
  "allowed_origins": [
    "https://tu-app.com",
    "https://staging.tu-app.com",
    "http://localhost:3000"
  ],
  "allowed_methods": ["GET", "POST", "PUT", "DELETE"],
  "allowed_headers": ["Content-Type", "X-API-Key"],
  "max_age": 86400
}
```

## Gestión de API Keys

### Crear una Nueva API Key

<Steps>
  <Step title="Acceder a la Gestión de Claves">
    Ve a **LatePoint > API Settings > API Keys**
  </Step>
  
  <Step title="Generar Nueva Clave">
    1. Haz clic en **"Generate New API Key"**
    2. Asigna un nombre descriptivo (ej: "App Móvil iOS")
    3. Selecciona el entorno (Test/Live)
  </Step>
  
  <Step title="Configurar Permisos">
    Selecciona los permisos necesarios:
    - **Bookings**: Read, Create, Update, Delete
    - **Customers**: Read, Create, Update
    - **Agents**: Read
    - **Services**: Read
    - **Availability**: Read
  </Step>
  
  <Step title="Configurar Restricciones">
    - Rate limiting personalizado
    - Restricciones de IP
    - Fecha de expiración (opcional)
  </Step>
  
  <Step title="Guardar y Copiar">
    1. Haz clic en **"Generate"**
    2. **Copia la API Key inmediatamente**
    3. Guárdala en un lugar seguro
  </Step>
</Steps>

### Tipos de Permisos

<AccordionGroup>
  <Accordion title="Bookings (Reservas)">
    - **Read**: Consultar reservas existentes
    - **Create**: Crear nuevas reservas
    - **Update**: Modificar reservas existentes
    - **Delete**: Eliminar reservas
    - **Status**: Cambiar estado de reservas
  </Accordion>
  
  <Accordion title="Customers (Clientes)">
    - **Read**: Consultar información de clientes
    - **Create**: Registrar nuevos clientes
    - **Update**: Actualizar datos de clientes
    - **Delete**: Eliminar clientes (con restricciones)
  </Accordion>
  
  <Accordion title="Agents (Agentes)">
    - **Read**: Consultar lista de agentes
    - **Schedule**: Consultar horarios de agentes
  </Accordion>
  
  <Accordion title="Services (Servicios)">
    - **Read**: Consultar servicios disponibles
    - **Pricing**: Acceder a información de precios
  </Accordion>
  
  <Accordion title="Availability (Disponibilidad)">
    - **Read**: Verificar disponibilidad de horarios
    - **Block**: Bloquear horarios (si está habilitado)
  </Accordion>
</AccordionGroup>

## Configuración de Base de Datos

### Verificar Tablas

Verifica que todas las tablas se hayan creado correctamente:

```sql
-- Verificar tablas de la API
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'tu_base_de_datos' 
AND table_name LIKE 'wp_latepoint_api_%';
```

**Tablas esperadas:**
- `wp_latepoint_api_keys`
- `wp_latepoint_api_logs`
- `wp_latepoint_api_rate_limits`
- `wp_latepoint_license_info`

### Configuración de Índices

Para mejor rendimiento, verifica que existan estos índices:

```sql
-- Índices para logs de API
CREATE INDEX idx_api_logs_timestamp ON wp_latepoint_api_logs(timestamp);
CREATE INDEX idx_api_logs_api_key ON wp_latepoint_api_logs(api_key_id);

-- Índices para rate limiting
CREATE INDEX idx_rate_limits_window ON wp_latepoint_api_rate_limits(time_window);
```

## Configuración de Logs

### Niveles de Log

Configura qué eventos registrar:

- **Error**: Solo errores críticos
- **Warning**: Errores y advertencias
- **Info**: Información general de uso
- **Debug**: Información detallada (solo para desarrollo)

### Retención de Logs

Configura cuánto tiempo mantener los logs:

```json
{
  "retention_days": 30,
  "max_log_size_mb": 100,
  "auto_cleanup": true,
  "compress_old_logs": true
}
```

### Exportación de Logs

Puedes exportar logs para análisis:

1. Ve a **LatePoint > API Settings > Logs**
2. Selecciona el rango de fechas
3. Elige el formato (CSV, JSON, XML)
4. Haz clic en **"Export"**

## Configuración de Notificaciones

### Alertas de Seguridad

Configura alertas para eventos importantes:

- **Intentos de acceso no autorizados**
- **Límites de rate limiting excedidos**
- **Errores críticos de la API**
- **Uso inusual de API Keys**

## Configuración de Caché

### Caché de Respuestas

Para mejorar el rendimiento, habilita el caché:

```json
{
  "enabled": true,
  "ttl_seconds": 300,
  "cache_endpoints": [
    "services",
    "agents",
    "availability"
  ],
  "exclude_endpoints": [
    "bookings",
    "customers"
  ]
}
```

### Invalidación de Caché

El caché se invalida automáticamente cuando:
- Se crean/modifican servicios
- Se actualizan horarios de agentes
- Se cambian configuraciones de disponibilidad

## Configuración de Backup

### Backup Automático

Configura backups automáticos de la configuración:

```json
{
  "enabled": true,
  "frequency": "daily",
  "retention_days": 30,
  "include_logs": false,
  "storage_location": "wp-content/uploads/latepoint-backups/"
}
```

### Restauración

Para restaurar una configuración:

1. Ve a **LatePoint > API Settings > Backup**
2. Selecciona el backup a restaurar
3. Haz clic en **"Restore"**
4. Confirma la acción
