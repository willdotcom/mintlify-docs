---
title: "Create Coupon"
api: "POST /wp-json/latepoint-api/v1/coupons"
description: "Create a new coupon."
---

## Required Parameters

<ParamField body="code" type="string" required>
  Unique coupon code
</ParamField>

<ParamField body="name" type="string" required>
  Display name for the coupon
</ParamField>

## Optional Parameters

<ParamField body="description" type="string">
  Description of the coupon
</ParamField>

<ParamField body="discount_type" type="string" default="percent">
  Type of discount. Available values: `percent`, `fixed_amount`
</ParamField>

<ParamField body="discount_value" type="number" default="0">
  Discount value (percentage or fixed amount)
</ParamField>

<ParamField body="status" type="string" default="active">
  Coupon status. Available values: `active`, `inactive`
</ParamField>

<ParamField body="active_from" type="string">
  Start date for coupon validity (YYYY-MM-DD format)
</ParamField>

<ParamField body="active_to" type="string">
  End date for coupon validity (YYYY-MM-DD format)
</ParamField>

<ParamField body="usage_limit" type="integer" default="0">
  Maximum number of uses (0 = unlimited)
</ParamField>

<ParamField body="min_order_amount" type="number" default="0">
  Minimum order amount required to use coupon
</ParamField>

<ParamField body="max_discount_amount" type="number" default="0">
  Maximum discount amount (for percentage discounts)
</ParamField>

## Example Request

```bash
POST /wp-json/latepoint-api/v1/coupons
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "code": "TEST2025",
  "name": "Test Coupon 2025",
  "description": "Test coupon for API testing",
  "discount_type": "percent",
  "discount_value": 15,
  "status": "active"
}
```
