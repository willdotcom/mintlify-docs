---
title: "Get Event Category"
api: "GET /wp-json/latepoint-api/v1/events/categories/{id}"
description: "Retrieve a specific event category by ID."
---

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the category to retrieve
</ParamField>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events/categories/1
Authorization: Bearer YOUR_API_KEY
```

## Response

```json
{
  "success": true,
  "data": {
    "id": 1,
    "name": "Workshops",
    "short_description": "Hands-on group sessions",
    "order_number": 0,
    "status": "active",
    "created_at": "2026-10-20 14:05:10",
    "updated_at": "2026-10-20 14:05:10"
  }
}
```

## Error Response

```json
{
  "code": "event_category_not_found",
  "message": "Event category not found",
  "data": {
    "status": 404
  }
}
```
