---
title: "Get Event"
api: "GET /wp-json/latepoint-api/v1/events/{id}"
description: "Retrieve a specific event by ID, including its dates."
---

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the event to retrieve
</ParamField>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events/2
Authorization: Bearer YOUR_API_KEY
```
