---
title: "List Events"
api: "GET /wp-json/latepoint-api/v1/events"
description: "Retrieve a list of events with optional filtering, sorting and pagination."
---

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="per_page" type="integer" default="10">
  Number of events per page
</ParamField>

<ParamField query="search" type="string">
  Search events by name or summary
</ParamField>

<ParamField query="status" type="string">
  Filter by status. Available values: `draft`, `published`, `cancelled`, `completed`
</ParamField>

<ParamField query="category_id" type="integer">
  Filter by event category ID
</ParamField>

<ParamField query="event_type" type="string">
  Filter by event type. Available values: `in_person`, `online`
</ParamField>

<ParamField query="date_from" type="string">
  Only events whose dates end on or after this day (YYYY-MM-DD, site timezone)
</ParamField>

<ParamField query="date_to" type="string">
  Only events whose dates start on or before this day (YYYY-MM-DD, site timezone)
</ParamField>

<ParamField query="sort" type="string" default="start_datetime_utc">
  Field to sort results by. Valid values: `id`, `name`, `start_datetime_utc`, `created_at`, `order_number`, `price`
</ParamField>

<ParamField query="order" type="string" default="asc">
  Sort direction. Valid values: `asc`, `desc`
</ParamField>

<Note>
  List items do not include the `dates` array. Use [Get Event](/api-reference/events/get) or [List Event Dates](/api-reference/events/dates-list) to get them. See [Dates and times](/api-reference/events/overview#dates-and-times) for the timezone rules.
</Note>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events?status=published&date_from=2026-12-01&date_to=2026-12-31
Authorization: Bearer YOUR_API_KEY
```
