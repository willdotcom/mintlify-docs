---
title: "Get E-Ticket"
api: "GET /wp-json/latepoint-api/v1/events/tickets/{id}"
description: "Retrieve a specific e-ticket by ID."
---

<Note>
  **LatePoint Pro feature.** E-Tickets require LatePoint Pro Features with E-Tickets enabled in LatePoint settings. Otherwise this endpoint returns `503` (`feature_not_available` or `feature_disabled`). See [Pro features](/api-reference/events/overview#pro-features).
</Note>

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the ticket to retrieve
</ParamField>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events/tickets/1
Authorization: Bearer YOUR_API_KEY
```
