---
title: "List Event Dates"
api: "GET /wp-json/latepoint-api/v1/events/{id}/dates"
description: "Retrieve all dates of an event."
---

An event can have one or more dates. Each date has a `start` and `end` in the site timezone, plus the same values in UTC. See [Dates and times](/api-reference/events/overview#dates-and-times).

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the event
</ParamField>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events/2/dates
Authorization: Bearer YOUR_API_KEY
```

## Response

Dates are returned in a single array, without pagination.

```json
{
  "success": true,
  "data": [
    {
      "id": 1,
      "event_id": 2,
      "start": "2026-12-05 09:00:00",
      "end": "2026-12-05 12:00:00",
      "start_utc": "2026-12-05 12:00:00",
      "end_utc": "2026-12-05 15:00:00"
    },
    {
      "id": 2,
      "event_id": 2,
      "start": "2026-12-06 09:00:00",
      "end": "2026-12-06 12:00:00",
      "start_utc": "2026-12-06 12:00:00",
      "end_utc": "2026-12-06 15:00:00"
    }
  ]
}
```

## Error Response

```json
{
  "code": "event_not_found",
  "message": "Event not found",
  "data": {
    "status": 404
  }
}
```
