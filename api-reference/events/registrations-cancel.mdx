---
title: "Cancel Event Registration"
api: "POST /wp-json/latepoint-api/v1/events/registrations/{id}/cancel"
description: "Cancel an event registration, the same way as the Cancel action in the LatePoint admin."
---

Cancelling a registration:

- Sets its status to `cancelled`
- Sends LatePoint's cancellation notification
- Voids its e-tickets (LatePoint Pro)
- Frees its places in the event

Cancelling a registration that is already cancelled returns a successful response and changes nothing.

<Warning>
  Cancelling a registration does **not** cancel or refund its order. Use the [Orders](/api-reference/orders/update) and [Payments](/api-reference/payments/list) endpoints to handle the order.
</Warning>

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the registration to cancel
</ParamField>

## Example Request

```bash
POST /wp-json/latepoint-api/v1/events/registrations/1/cancel
Authorization: Bearer YOUR_API_KEY
```

## Error Responses

| Status | Code | Description |
|--------|------|-------------|
| `404` | `event_registration_not_found` | The registration does not exist |
| `503` | `feature_disabled` | Events is disabled in LatePoint settings |
