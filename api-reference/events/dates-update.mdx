---
title: "Update Event Date"
api: "PUT /wp-json/latepoint-api/v1/events/{id}/dates/{date_id}"
description: "Change the start and end of an event date."
---

The event's overall `start` and `end` are recalculated after the change.

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the event
</ParamField>

<ParamField path="date_id" type="integer" required>
  The ID of the date to update
</ParamField>

## Request Body Parameters

<ParamField body="start" type="string" required>
  Start of the date, `YYYY-MM-DD HH:MM` in the site timezone. See [Dates and times](/api-reference/events/overview#dates-and-times).
</ParamField>

<ParamField body="end" type="string">
  End of the date, `YYYY-MM-DD HH:MM` in the site timezone. Must be on or after `start`. Defaults to `start`.
</ParamField>

## Example Request

```bash
PUT /wp-json/latepoint-api/v1/events/2/dates/3
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "start": "2026-12-07 10:00",
  "end": "2026-12-07 13:00"
}
```

## Response

```json
{
  "success": true,
  "message": "Event date updated successfully",
  "data": {
    "id": 3,
    "event_id": 2,
    "start": "2026-12-07 10:00:00",
    "end": "2026-12-07 13:00:00",
    "start_utc": "2026-12-07 13:00:00",
    "end_utc": "2026-12-07 16:00:00"
  }
}
```

## Error Responses

| Status | Code | Description |
|--------|------|-------------|
| `400` | `invalid_dates` | `start` is missing, or `end` is before `start` |
| `400` | `invalid_datetime` | A value is not in `YYYY-MM-DD HH:MM` format |
| `404` | `event_not_found` | The event does not exist |
| `404` | `event_date_not_found` | The date does not exist or belongs to another event |
| `422` | `save_error` | LatePoint could not save the date |
| `503` | `feature_disabled` | Events is disabled in LatePoint settings |
