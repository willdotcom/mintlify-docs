---
title: "Invite From Waiting List"
api: "POST /wp-json/latepoint-api/v1/events/waiting-list/{id}/invite"
description: "Offer a free place to a customer on the waiting list. Use this for paid events."
---

<Note>
  **LatePoint Pro feature.** The waiting list requires LatePoint Pro Features with Waiting List enabled in LatePoint settings. Otherwise this endpoint returns `503` (`feature_not_available` or `feature_disabled`). See [Pro features](/api-reference/events/overview#pro-features).
</Note>

Inviting offers the place to the customer: LatePoint emails them a link to claim it, and they complete the checkout (and payment) themselves. The invitation expires after 2 days, or when registration for the event closes if that is sooner.

The entry's status becomes `invited`. For free events you can also give the place directly with [Promote From Waiting List](/api-reference/events/waiting-list-promote).

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the waiting list entry
</ParamField>

## Example Request

```bash
POST /wp-json/latepoint-api/v1/events/waiting-list/1/invite
Authorization: Bearer YOUR_API_KEY
```

## Error Responses

When LatePoint cannot offer the place (the event is still full, registration has closed, the entry is no longer active...), the request fails with `409` and LatePoint's own explanation:

```json
{
  "code": "waiting_list_action_failed",
  "message": "This event is full. Increase the event capacity by at least 1 place, then offer it again.",
  "data": {
    "status": 409
  }
}
```

Other errors: `404 waiting_list_entry_not_found`, `503 feature_disabled`.
