---
title: "List E-Tickets"
api: "GET /wp-json/latepoint-api/v1/events/tickets"
description: "Retrieve event e-tickets with optional filtering and pagination."
---

<Note>
  **LatePoint Pro feature.** E-Tickets require LatePoint Pro Features with E-Tickets enabled in LatePoint settings. Otherwise this endpoint returns `503` (`feature_not_available` or `feature_disabled`). See [Pro features](/api-reference/events/overview#pro-features).
</Note>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="per_page" type="integer" default="10">
  Number of tickets per page
</ParamField>

<ParamField query="event_id" type="integer">
  Filter by event ID
</ParamField>

<ParamField query="registration_id" type="integer">
  Filter by registration ID
</ParamField>

<ParamField query="customer_id" type="integer">
  Filter by customer ID
</ParamField>

<ParamField query="ticket_type_id" type="integer">
  Filter by ticket type ID
</ParamField>

<ParamField query="status" type="string">
  Filter by status. Available values: `issued`, `checked_in`, `void`
</ParamField>

<ParamField query="code" type="string">
  Find a ticket by its code. Accepts the raw ticket code, the ticket URL or the content of its QR code.
</ParamField>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events/tickets?registration_id=1
Authorization: Bearer YOUR_API_KEY
```

## Response Fields

<ResponseField name="id" type="integer">
  Unique identifier for the ticket
</ResponseField>

<ResponseField name="ticket_code" type="string">
  Ticket code (encoded in the QR code)
</ResponseField>

<ResponseField name="label" type="string">
  Display label, for example `Ticket 1 of 2`
</ResponseField>

<ResponseField name="registration_id" type="integer">
  Registration the ticket belongs to
</ResponseField>

<ResponseField name="event_id" type="integer">
  Event ID
</ResponseField>

<ResponseField name="customer_id" type="integer">
  Customer ID
</ResponseField>

<ResponseField name="ticket_number" type="integer">
  Attendee number within the registration (`0` for a group ticket)
</ResponseField>

<ResponseField name="ticket_type" type="string">
  `individual` (one ticket per attendee) or `group` (one ticket covering the whole registration)
</ResponseField>

<ResponseField name="ticket_type_id" type="integer">
  Ticket type ID, when the event uses ticket types
</ResponseField>

<ResponseField name="ticket_type_name" type="string">
  Ticket type name, when the event uses ticket types
</ResponseField>

<ResponseField name="status" type="string">
  `issued`, `checked_in` or `void`
</ResponseField>

<ResponseField name="checked_in_dates" type="array">
  One entry per day the ticket was checked in: `date` (YYYY-MM-DD), `at` (date and time) and `by` (ID of the agent or WordPress user who checked it in, `0` when none)
</ResponseField>

<ResponseField name="last_scanned_at" type="string">
  When the ticket was last scanned
</ResponseField>

<ResponseField name="public_url" type="string">
  Public page of the ticket
</ResponseField>

<ResponseField name="qr_image_url" type="string">
  QR code image
</ResponseField>

<ResponseField name="pdf_url" type="string">
  PDF download
</ResponseField>

<ResponseField name="created_at" type="string">
  Creation timestamp
</ResponseField>
