---
title: "Get Event Registration"
api: "GET /wp-json/latepoint-api/v1/events/registrations/{id}"
description: "Retrieve a specific event registration by ID, including its e-tickets."
---

## Path Parameters

<ParamField path="id" type="integer" required>
  The ID of the registration to retrieve
</ParamField>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events/registrations/1
Authorization: Bearer YOUR_API_KEY
```
