---
title: "Create Event Category"
api: "POST /wp-json/latepoint-api/v1/events/categories"
description: "Create a new event category."
---

## Required Parameters

<ParamField body="name" type="string" required>
  Category name
</ParamField>

## Optional Parameters

<ParamField body="short_description" type="string">
  Brief description of the category
</ParamField>

<ParamField body="order_number" type="integer">
  Display order
</ParamField>

<ParamField body="status" type="string" default="active">
  Category status
</ParamField>

## Example Request

```bash
POST /wp-json/latepoint-api/v1/events/categories
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

{
  "name": "Workshops",
  "short_description": "Hands-on group sessions",
  "order_number": 0
}
```

## Response

Returns `201 Created`:

```json
{
  "success": true,
  "message": "Event category created successfully",
  "data": {
    "id": 1,
    "name": "Workshops",
    "short_description": "Hands-on group sessions",
    "order_number": 0,
    "status": "active",
    "created_at": "2026-10-20 14:05:10",
    "updated_at": "2026-10-20 14:05:10"
  }
}
```

## Error Responses

| Status | Code | Description |
|--------|------|-------------|
| `400` | `missing_field` | `name` is missing |
| `422` | `save_error` | LatePoint could not save the category |
| `503` | `feature_disabled` | Events is disabled in LatePoint settings |
