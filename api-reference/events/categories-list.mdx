---
title: "List Event Categories"
api: "GET /wp-json/latepoint-api/v1/events/categories"
description: "Retrieve a list of event categories with pagination."
---

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="per_page" type="integer" default="10">
  Number of categories per page
</ParamField>

<ParamField query="status" type="string">
  Filter categories by status, for example `active`
</ParamField>

Categories are ordered by `order_number`, then by `name`.

## Example Request

```bash
GET /wp-json/latepoint-api/v1/events/categories?status=active
Authorization: Bearer YOUR_API_KEY
```

## Response Fields

  Unique identifier for the category
</ResponseField>
