---
title: "List Payments"
api: "GET /wp-json/latepoint-api/v1/payments"
description: "Retrieve a list of all payments with pagination support."
---

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for pagination
</ParamField>

<ParamField query="per_page" type="integer" default="10">
  Number of payments per page
</ParamField>

<ParamField query="customer_id" type="integer">
  Filter payments by customer ID
</ParamField>

<ParamField query="order_id" type="integer">
  Filter payments by order ID
</ParamField>

<ParamField query="status" type="string">
  Filter payments by status (succeeded, processing, failed)
</ParamField>

<ParamField query="payment_method" type="string">
  Filter payments by payment method
</ParamField>

## Example Request

```bash
GET /wp-json/latepoint-api/v1/payments?page=1&per_page=10&status=completed
X-API-Key: YOUR_API_KEY
Content-Type: application/json
```
