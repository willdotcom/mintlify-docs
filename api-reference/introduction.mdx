## Bienvenido a LatePoint API

LatePoint API Extension proporciona una interfaz REST completa para interactuar con tu sistema de reservas LatePoint. Esta API te permite integrar LatePoint con aplicaciones externas, crear automatizaciones personalizadas y construir experiencias de usuario únicas.

## URL Base

Todas las solicitudes a la API utilizan la siguiente URL base:

```
https://tu-sitio.com/wp-json/latepoint/v1/
```

## Autenticación

Cada solicitud debe incluir tu API Key en el header:

```http
X-API-Key: tu_api_key_aqui
```

[Aprende más sobre autenticación →](/authentication)

## Estructura de Respuestas

### Respuestas Exitosas

Todas las respuestas exitosas siguen esta estructura:

```json
{
  "status": "success",
  "data": {
    // Datos solicitados
  },
  "meta": {
    "total": 100,
    "page": 1,
    "per_page": 20,
    "total_pages": 5
  }
}
```

### Respuestas de Error

Los errores siguen esta estructura:

```json
{
  "status": "error",
  "error": {
    "code": "invalid_request",
    "message": "Descripción del error",
    "details": {
      "field": "Información adicional"
    }
  }
}
```

## Códigos de Estado HTTP

| Código | Significado | Descripción |
|--------|-------------|-------------|
| 200 | OK | Solicitud exitosa |
| 201 | Created | Recurso creado exitosamente |
| 400 | Bad Request | Solicitud malformada |
| 401 | Unauthorized | API Key faltante o inválida |
| 403 | Forbidden | Permisos insuficientes |
| 404 | Not Found | Recurso no encontrado |
| 422 | Unprocessable Entity | Datos de entrada inválidos |
| 429 | Too Many Requests | Rate limit excedido |
| 500 | Internal Server Error | Error del servidor |

## Paginación

### Parámetros de Paginación

Los endpoints que devuelven listas soportan paginación:

```http
GET /bookings?page=2&per_page=50
```

**Parámetros:**
- `page`: Número de página (por defecto: 1)
- `per_page`: Elementos por página (por defecto: 20, máximo: 100)

### Respuesta con Paginación

```json
{
  "status": "success",
  "data": [...],
  "meta": {
    "total": 150,
    "page": 2,
    "per_page": 50,
    "total_pages": 3,
    "has_next_page": true,
    "has_prev_page": true
  }
}
```

## Filtrado y Búsqueda

### Filtros Comunes

La mayoría de endpoints soportan filtros:

```http
GET /bookings?status=confirmed&date_from=2024-01-01&date_to=2024-01-31
```

### Búsqueda de Texto

Para búsquedas de texto libre:

```http
GET /customers?search=juan+perez
```

### Ordenamiento

Especifica el orden de los resultados:

```http
GET /bookings?sort=start_date&order=desc
```

**Parámetros:**
- `sort`: Campo por el cual ordenar
- `order`: `asc` (ascendente) o `desc` (descendente)

## Rate Limiting

### Límites por Defecto

| Tipo de API Key | Por Minuto | Por Hora |
|-----------------|------------|----------|
| Test | 100 | 1,000 |
| Live | 60 | 3,600 |

### Headers de Rate Limiting

Cada respuesta incluye información sobre tu uso actual:

```http
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 45
X-RateLimit-Reset: 1640995200
```

[Aprende más sobre rate limiting →](/api-reference/rate-limiting)

## Recursos Disponibles

### Bookings (Reservas)

Gestión completa de reservas:

- **GET** `/bookings` - Listar reservas
- **POST** `/bookings` - Crear reserva
- **GET** `/bookings/{id}` - Obtener reserva
- **PUT** `/bookings/{id}` - Actualizar reserva
- **DELETE** `/bookings/{id}` - Eliminar reserva

[Ver documentación completa →](/api-reference/bookings/list)

### Customers (Clientes)

Administración de clientes:

- **GET** `/customers` - Listar clientes
- **POST** `/customers` - Crear cliente
- **GET** `/customers/{id}` - Obtener cliente
- **PUT** `/customers/{id}` - Actualizar cliente

[Ver documentación completa →](/api-reference/customers/list)

### Agents (Agentes)

Consulta de agentes y horarios:

- **GET** `/agents` - Listar agentes
- **GET** `/agents/{id}` - Obtener agente

[Ver documentación completa →](/api-reference/agents/list)

### Services (Servicios)

Consulta de servicios disponibles:

- **GET** `/services` - Listar servicios
- **GET** `/services/{id}` - Obtener servicio

[Ver documentación completa →](/api-reference/services/list)

### Availability (Disponibilidad)

Verificación de disponibilidad:

- **GET** `/availability` - Verificar disponibilidad

[Ver documentación completa →](/api-reference/availability/check)

## Formatos de Fecha y Hora

### Formato ISO 8601

Todas las fechas y horas utilizan formato ISO 8601:

```json
{
  "start_date": "2024-01-15",
  "start_time": "14:30",
  "created_at": "2024-01-15T14:30:00Z"
}
```

### Zona Horaria

Las fechas se manejan en la zona horaria configurada en WordPress. Para obtener la zona horaria actual:

```http
GET /status
```

```json
{
  "status": "success",
  "data": {
    "timezone": "America/Mexico_City",
    "current_time": "2024-01-15T14:30:00-06:00"
  }
}
```

## Versionado

### Versión Actual

La versión actual de la API es `v1`. Todas las URLs incluyen la versión:

```
/wp-json/latepoint/v1/
```

### Compatibilidad

Nos comprometemos a mantener la compatibilidad hacia atrás dentro de la misma versión mayor. Los cambios que rompan la compatibilidad se introducirán en nuevas versiones.
