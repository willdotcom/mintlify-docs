## Descripción

Este endpoint permite actualizar una reserva existente. Puedes modificar cualquier campo de la reserva, incluyendo horarios, estado, información del cliente y notas.

## Autenticación

<ParamField header="X-API-Key" type="string" required>
  Tu API Key de LatePoint con permisos de escritura
</ParamField>

## Parámetros de Ruta

<ParamField path="id" type="integer" required>
  ID único de la reserva a actualizar
</ParamField>

## Cuerpo de la Solicitud

### Campos de Reserva

<ParamField body="service_id" type="integer">
  ID del servicio (requiere verificación de disponibilidad si cambia)
</ParamField>

<ParamField body="agent_id" type="integer">
  ID del agente (requiere verificación de disponibilidad si cambia)
</ParamField>

<ParamField body="location_id" type="integer">
  ID de la ubicación
</ParamField>

<ParamField body="start_date" type="string">
  Nueva fecha de la reserva (formato: YYYY-MM-DD)
</ParamField>

<ParamField body="start_time" type="string">
  Nueva hora de inicio (formato: HH:MM en formato 24 horas)
</ParamField>

<ParamField body="duration" type="integer">
  Duración personalizada en minutos
</ParamField>

<ParamField body="status" type="string">
  Estado de la reserva
  
  **Valores posibles:**
  - `pending` - Pendiente
  - `confirmed` - Confirmada
  - `cancelled` - Cancelada
  - `completed` - Completada
  - `no_show` - No se presentó
</ParamField>

### Información del Cliente

<ParamField body="customer_id" type="integer">
  Cambiar a un cliente diferente (ID del cliente)
</ParamField>

<ParamField body="customer.first_name" type="string">
  Actualizar nombre del cliente
</ParamField>

<ParamField body="customer.last_name" type="string">
  Actualizar apellido del cliente
</ParamField>

<ParamField body="customer.email" type="string">
  Actualizar email del cliente
</ParamField>

<ParamField body="customer.phone" type="string">
  Actualizar teléfono del cliente
</ParamField>

### Campos Adicionales

<ParamField body="price" type="string">
  Precio personalizado para esta reserva
</ParamField>

<ParamField body="notes" type="string">
  Notas públicas de la reserva
</ParamField>

<ParamField body="internal_notes" type="string">
  Notas internas (solo visible para staff)
</ParamField>

<ParamField body="payment_status" type="string">
  Estado del pago
  
  **Valores posibles:**
  - `not_paid` - No pagado
  - `partially_paid` - Parcialmente pagado
  - `paid` - Pagado
  - `refunded` - Reembolsado
</ParamField>

<ParamField body="payment_method" type="string">
  Método de pago utilizado
</ParamField>

<ParamField body="send_notification" type="boolean" default="false">
  Si enviar notificación al cliente sobre los cambios
</ParamField>

<ParamField body="custom_fields" type="object">
  Campos personalizados de la reserva
</ParamField>

<ResponseField name="data" type="object">

<ResponseField name="changes" type="object">

  </Expandable>
</ResponseField>

## Validaciones

### Validaciones Automáticas

1. **Disponibilidad**: Si cambias fecha, hora o agente, se verifica disponibilidad
2. **Estados Válidos**: Solo permite transiciones de estado válidas
3. **Fechas**: No permite cambiar a fechas pasadas
4. **Email Único**: Verifica que el email no esté en uso por otro cliente
5. **Permisos**: Verifica que tengas permisos para modificar la reserva

### Reglas de Transición de Estado

| Estado Actual | Estados Permitidos |
|---------------|--------------------|
| `pending` | `confirmed`, `cancelled` |
| `confirmed` | `completed`, `cancelled`, `no_show` |
| `cancelled` | `pending`, `confirmed` |
| `completed` | `cancelled` (solo con permisos especiales) |
| `no_show` | `confirmed`, `cancelled` |

## Casos de Uso Comunes

### 1. Confirmar Reserva Pendiente

```javascript
// Confirmar una reserva que estaba pendiente
async function confirmBooking(bookingId) {
  const response = await fetch(`/wp-json/latepoint/v1/bookings/${bookingId}`, {
    method: 'PUT',
    headers: {
      'X-API-Key': 'tu_api_key',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      status: 'confirmed',
      send_notification: true
    })
  });
  
  if (response.ok) {
    const result = await response.json();
    console.log('Reserva confirmada:', result.data.booking_code);
    return result.data;
  }
  
  throw new Error('Error al confirmar la reserva');
}
```

### 2. Reprogramar con Verificación de Disponibilidad

```javascript
// Reprogramar una reserva verificando disponibilidad primero
async function rescheduleBooking(bookingId, newDate, newTime, agentId, serviceId) {
  // Primero verificar disponibilidad
  const availabilityResponse = await fetch(
    `/wp-json/latepoint/v1/availability?service_id=${serviceId}&agent_id=${agentId}&date=${newDate}`
  );
  
  const availability = await availabilityResponse.json();
  
  if (!availability.data.available_slots.includes(newTime)) {
    throw new Error('El horario solicitado no está disponible');
  }
  
  // Proceder con la reprogramación
  const response = await fetch(`/wp-json/latepoint/v1/bookings/${bookingId}`, {
    method: 'PUT',
    headers: {
      'X-API-Key': 'tu_api_key',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      start_date: newDate,
      start_time: newTime,
      send_notification: true,
      notes: 'Reprogramada por solicitud del cliente'
    })
  });
  
  return await response.json();
}
```

### 3. Actualización Masiva de Estado

```javascript
// Marcar múltiples reservas como completadas
async function markBookingsCompleted(bookingIds) {
  const results = [];
  
  for (const bookingId of bookingIds) {
    try {
      const response = await fetch(`/wp-json/latepoint/v1/bookings/${bookingId}`, {
        method: 'PUT',
        headers: {
          'X-API-Key': 'tu_api_key',
          'Content-Type': 'application/json'
        },
        body: JSON.stringify({
          status: 'completed',
          internal_notes: 'Marcada como completada automáticamente'
        })
      });
      
      if (response.ok) {
        const result = await response.json();
        results.push({ id: bookingId, success: true, data: result.data });
      } else {
        results.push({ id: bookingId, success: false, error: await response.json() });
      }
    } catch (error) {
      results.push({ id: bookingId, success: false, error: error.message });
    }
  }
  
  return results;
}
```

// Actualizar el estado de pago de una reserva
async function updatePaymentStatus(bookingId, paymentStatus, paymentMethod = null) {
  const updateData = {

    },
    body: JSON.stringify(updateData)

  return await response.json();

## Notas Importantes

<Note>
  **Actualización Parcial**: Solo necesitas enviar los campos que quieres actualizar. Los campos no incluidos mantendrán sus valores actuales.
</Note>

<Warning>
  **Verificación de Disponibilidad**: Siempre verifica la disponibilidad antes de cambiar fecha, hora o agente para evitar conflictos.
</Warning>

<Tip>
  **Notificaciones**: Usa `send_notification: true` para informar automáticamente al cliente sobre cambios importantes en su reserva.
</Tip>

## Mejores Prácticas

### 1. Verificación Previa

```javascript
// Siempre obtén los datos actuales antes de actualizar
const currentBooking = await fetch(`/wp-json/latepoint/v1/bookings/${bookingId}`);
const bookingData = await currentBooking.json();

// Luego realiza la actualización con los nuevos valores
```

### 2. Manejo de Errores

```javascript
// Implementa manejo robusto de errores
try {
  const response = await fetch(`/wp-json/latepoint/v1/bookings/${bookingId}`, {
    method: 'PUT',
    body: JSON.stringify(updateData)
  });
  
  if (!response.ok) {
    const error = await response.json();
    
    if (error.error.code === 'time_slot_unavailable') {
      // Mostrar horarios alternativos
      console.log('Horarios disponibles:', error.error.details.available_slots);
    }
    
    throw new Error(error.error.message);
  }
  
  const result = await response.json();
  return result.data;
} catch (error) {
  console.error('Error al actualizar reserva:', error.message);
  throw error;
}
```
