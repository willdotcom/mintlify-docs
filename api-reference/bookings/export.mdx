### Response
Returns a CSV file download containing booking records.

### CSV Columns
| Column | Description |
| :--- | :--- |
| ID | Booking ID |
| Service | Service Name |
| Start Date | Start Date |
| Start Time | Start Time |
| Duration | Duration in minutes |
| Customer | Customer Name |
| Agent | Agent Name |
| Status | Booking Status |
| Price | Price |
| ... | And more standard columns |
