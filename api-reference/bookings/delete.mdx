## Descripción

Este endpoint permite eliminar permanentemente una reserva del sistema. Esta acción es irreversible y debe usarse con precaución.

<Warning>
  **Acción Irreversible**: Una vez eliminada, la reserva no puede ser recuperada. Considera usar el estado `cancelled` en su lugar si necesitas mantener un registro histórico.
</Warning>

## Autenticación

<ParamField header="X-API-Key" type="string" required>
  Tu API Key de LatePoint con permisos de eliminación
</ParamField>

## Parámetros de Ruta

<ParamField path="id" type="integer" required>
  ID único de la reserva a eliminar
</ParamField>

## Parámetros de Consulta

<ParamField query="force" type="boolean" default="false">
  Forzar eliminación incluso si la reserva está confirmada o completada
</ParamField>

<ParamField query="notify_customer" type="boolean" default="false">
  Enviar notificación de cancelación al cliente antes de eliminar
</ParamField>

<ParamField query="reason" type="string">
  Razón de la eliminación (se incluirá en logs de auditoría)
</ParamField>

## Reglas de Eliminación

### Estados que Permiten Eliminación Directa

- `pending` - Pendiente
- `cancelled` - Cancelada

### Estados que Requieren `force=true`

- `confirmed` - Confirmada
- `completed` - Completada
- `no_show` - No se presentó

### Restricciones de Eliminación

1. **Pagos Procesados**: Reservas con pagos completados requieren manejo especial
2. **Paquetes de Servicios**: Reservas parte de un paquete no pueden eliminarse individualmente
3. **Dependencias**: Reservas con citas de seguimiento vinculadas
4. **Período de Retención**: Algunas configuraciones pueden requerir mantener registros por tiempo específico

## Casos de Uso Comunes

### 1. Eliminación Segura con Verificación

```javascript
// Función para eliminar reserva con verificaciones previas
async function safeDeleteBooking(bookingId, reason = null) {
  try {
    // Primero obtener información de la reserva
    const bookingResponse = await fetch(`/wp-json/latepoint/v1/bookings/${bookingId}`, {
      headers: { 'X-API-Key': 'tu_api_key' }
    });
    
    if (!bookingResponse.ok) {
      throw new Error('Reserva no encontrada');
    }
    
    const booking = await bookingResponse.json();
    const bookingData = booking.data;
    
    // Verificar si necesita forzar eliminación
    const needsForce = ['confirmed', 'completed', 'no_show'].includes(bookingData.status);
    
    // Construir parámetros
    const params = new URLSearchParams();
    if (needsForce) params.append('force', 'true');
    if (reason) params.append('reason', reason);
    params.append('notify_customer', 'true');
    
    // Eliminar reserva
    const deleteResponse = await fetch(
      `/wp-json/latepoint/v1/bookings/${bookingId}?${params}`,
      {
        method: 'DELETE',
        headers: { 'X-API-Key': 'tu_api_key' }
      }
    );
    
    if (deleteResponse.ok) {
      const result = await deleteResponse.json();
      console.log('Reserva eliminada:', result.data.booking_code);
      return result;
    } else {
      const error = await deleteResponse.json();
      throw new Error(error.error.message);
    }
    
  } catch (error) {
    console.error('Error al eliminar reserva:', error.message);
    throw error;
  }
}

// Uso
await safeDeleteBooking(123, 'Cancelación por parte del cliente');
```

### 2. Eliminación Masiva con Manejo de Errores

```javascript
// Eliminar múltiples reservas con manejo robusto de errores
async function bulkDeleteBookings(bookingIds, reason = null) {
  const results = {
    successful: [],
    failed: [],
    summary: {
      total: bookingIds.length,
      deleted: 0,
      errors: 0
    }
  };
  
  for (const bookingId of bookingIds) {
    try {
      const params = new URLSearchParams({
        force: 'true',
        notify_customer: 'true'
      });
      
      if (reason) params.append('reason', reason);
      
      const response = await fetch(
        `/wp-json/latepoint/v1/bookings/${bookingId}?${params}`,
        {
          method: 'DELETE',
          headers: { 'X-API-Key': 'tu_api_key' }
        }
      );
      
      if (response.ok) {
        const result = await response.json();
        results.successful.push({
          booking_id: bookingId,
          booking_code: result.data.booking_code,
          deleted_at: result.data.deleted_at
        });
        results.summary.deleted++;
      } else {
        const error = await response.json();
        results.failed.push({
          booking_id: bookingId,
          error: error.error.message,
          code: error.error.code
        });
        results.summary.errors++;
      }
      
    } catch (error) {
      results.failed.push({
        booking_id: bookingId,
        error: error.message,
        code: 'network_error'
      });
      results.summary.errors++;
    }
    
    // Pequeña pausa para evitar rate limiting
    await new Promise(resolve => setTimeout(resolve, 100));
  }
  
  return results;
}

// Uso
const bookingIds = [123, 124, 125, 126];
const results = await bulkDeleteBookings(bookingIds, 'Limpieza de datos obsoletos');

console.log(`Eliminadas: ${results.summary.deleted}/${results.summary.total}`);
if (results.failed.length > 0) {
  console.log('Errores:', results.failed);
}
```

### 3. Eliminación con Confirmación del Usuario

```javascript
// Función con confirmación interactiva
async function deleteBookingWithConfirmation(bookingId) {
  try {
    // Obtener detalles de la reserva
    const response = await fetch(`/wp-json/latepoint/v1/bookings/${bookingId}`, {
      headers: { 'X-API-Key': 'tu_api_key' }
    });
    
    const booking = await response.json();
    const data = booking.data;
    
    // Mostrar información de la reserva
    const confirmMessage = `
¿Estás seguro de que quieres eliminar esta reserva?

Código: ${data.booking_code}
Cliente: ${data.customer.first_name} ${data.customer.last_name}
Servicio: ${data.service.name}
Fecha: ${data.start_date} ${data.start_time}
Estado: ${data.status}

Esta acción no se puede deshacer.
    `;
    
    if (confirm(confirmMessage)) {
      const reason = prompt('Razón de la eliminación (opcional):');
      
      const params = new URLSearchParams({
        force: 'true',
        notify_customer: 'true'
      });
      
      if (reason) params.append('reason', reason);
      
      const deleteResponse = await fetch(
        `/wp-json/latepoint/v1/bookings/${bookingId}?${params}`,
        {
          method: 'DELETE',
          headers: { 'X-API-Key': 'tu_api_key' }
        }
      );
      
      if (deleteResponse.ok) {
        const result = await deleteResponse.json();
        alert(`Reserva ${result.data.booking_code} eliminada exitosamente`);
        return result;
      } else {
        const error = await deleteResponse.json();
        alert(`Error: ${error.error.message}`);
        throw new Error(error.error.message);
      }
    } else {
      console.log('Eliminación cancelada por el usuario');
      return null;
    }
    
  } catch (error) {
    console.error('Error:', error.message);
    alert(`Error al eliminar la reserva: ${error.message}`);
    throw error;
  }
}
```

### 4. Limpieza de Reservas Antiguas

```javascript
// Función para limpiar reservas antiguas automáticamente
async function cleanupOldBookings(daysOld = 365, status = 'cancelled') {
  try {
    // Calcular fecha límite
    const cutoffDate = new Date();
    cutoffDate.setDate(cutoffDate.getDate() - daysOld);
    const cutoffDateStr = cutoffDate.toISOString().split('T')[0];
    
    // Buscar reservas antiguas
    const searchParams = new URLSearchParams({
      status: status,
      end_date_before: cutoffDateStr,
      per_page: 100
    });
    
    const response = await fetch(
      `/wp-json/latepoint/v1/bookings?${searchParams}`,
      {
        headers: { 'X-API-Key': 'tu_api_key' }
      }
    );
    
    const bookings = await response.json();
    
    if (bookings.data.length === 0) {
      console.log('No se encontraron reservas antiguas para eliminar');
      return { deleted: 0, errors: 0 };
    }
    
    console.log(`Encontradas ${bookings.data.length} reservas para eliminar`);
    
    // Eliminar reservas en lotes
    const bookingIds = bookings.data.map(booking => booking.id);
    const results = await bulkDeleteBookings(
      bookingIds, 
      `Limpieza automática - reservas ${status} de más de ${daysOld} días`
    );
    
    console.log(`Limpieza completada: ${results.summary.deleted} eliminadas, ${results.summary.errors} errores`);
    
    return results.summary;
    
  } catch (error) {
    console.error('Error en limpieza automática:', error.message);
    throw error;
  }
}

// Programar limpieza mensual
setInterval(() => {
  cleanupOldBookings(365, 'cancelled')
    .then(summary => {
      console.log('Limpieza automática completada:', summary);
    })
    .catch(error => {
      console.error('Error en limpieza automática:', error);
    });
}, 30 * 24 * 60 * 60 * 1000); // 30 días
```

## Notas Importantes

<Note>
  **Eliminación vs Cancelación**: En la mayoría de casos, es mejor cancelar una reserva (cambiar estado a `cancelled`) que eliminarla permanentemente.
</Note>

<Warning>
  **Datos Irrecuperables**: Una vez eliminada, toda la información de la reserva se pierde permanentemente. Asegúrate de tener backups si es necesario.
</Warning>

<Tip>
  **Auditoría**: Siempre proporciona una razón para la eliminación. Esto ayuda con la auditoría y el seguimiento de cambios.
</Tip>

<Info>
  **Notificaciones**: Usa `notify_customer=true` para informar al cliente sobre la cancelación antes de eliminar la reserva.
</Info>

## Alternativas a la Eliminación
