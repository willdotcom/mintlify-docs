## Description

This endpoint allows you to permanently delete a booking from the system. This action is irreversible and should be used with caution.

<Warning>
  **Irreversible Action**: Once deleted, the booking cannot be recovered. Consider using the `cancelled` status instead if you need to maintain a historical record.
</Warning>

## Authentication

<ParamField header="X-API-Key" type="string" required>
  Your LatePoint API Key with deletion permissions
</ParamField>

## Path Parameters

<ParamField path="id" type="integer" required>
  Unique ID of the booking to delete
</ParamField>

## Query Parameters

<ParamField query="force" type="boolean" default="false">
  Force deletion even if the booking is confirmed or completed
</ParamField>

<ParamField query="notify_customer" type="boolean" default="false">
  Send cancellation notification to the customer before deleting
</ParamField>

<ParamField query="reason" type="string">
  Reason for deletion (will be included in audit logs)
</ParamField>

<ResponseField name="message" type="string">

## Deletion Rules

### States that Allow Direct Deletion

- `pending` - Pending
- `cancelled` - Cancelled

### States that Require `force=true`

- `confirmed` - Confirmed
- `completed` - Completed
- `no_show` - No show

### Deletion Restrictions

1. **Processed Payments**: Bookings with completed payments require special handling
2. **Service Packages**: Bookings that are part of a package cannot be deleted individually
3. **Dependencies**: Bookings with linked follow-up appointments
4. **Retention Period**: Some configurations may require maintaining records for a specific time

## Common Use Cases

### 1. Safe Deletion with Verification

```javascript
// Function to delete booking with prior verifications
async function safeDeleteBooking(bookingId, reason = null) {
  try {
    // First get booking information
    const bookingResponse = await fetch(`/wp-json/latepoint-api/v1/bookings/${bookingId}`, {
      headers: { 'X-API-Key': 'your_api_key' }
    });
    
    if (!bookingResponse.ok) {
      throw new Error('Booking not found');
    }
    
    const booking = await bookingResponse.json();
    const bookingData = booking.data;
    
    // Check if force deletion is needed
    const needsForce = ['confirmed', 'completed', 'no_show'].includes(bookingData.status);
    
    // Build parameters
    const params = new URLSearchParams();
    if (needsForce) params.append('force', 'true');
    if (reason) params.append('reason', reason);
    params.append('notify_customer', 'true');
    
    // Delete booking
    const deleteResponse = await fetch(
      `/wp-json/latepoint-api/v1/bookings/${bookingId}?${params}`,
      {
        method: 'DELETE',
        headers: { 'X-API-Key': 'your_api_key' }
      }
    );
    
    if (deleteResponse.ok) {
      const result = await deleteResponse.json();
      console.log('Booking deleted:', result.data.booking_code);
      return result;
    } else {
      const error = await deleteResponse.json();
      throw new Error(error.error.message);
    }
    
  } catch (error) {
    console.error('Error deleting booking:', error.message);
    throw error;
  }
}

// Usage
await safeDeleteBooking(123, 'Customer cancellation request');
```

### 2. Bulk Deletion with Error Handling

```javascript
// Delete multiple bookings with robust error handling
async function bulkDeleteBookings(bookingIds, reason = null) {
  const results = {
    successful: [],
    failed: [],
    summary: {
      total: bookingIds.length,
      deleted: 0,
      errors: 0
    }
  };
  
  for (const bookingId of bookingIds) {
    try {
      const params = new URLSearchParams({
        force: 'true',
        notify_customer: 'true'
      });
      
      if (reason) params.append('reason', reason);
      
      const response = await fetch(
        `/wp-json/latepoint-api/v1/bookings/${bookingId}?${params}`,
        {
          method: 'DELETE',
          headers: { 'X-API-Key': 'your_api_key' }
        }
      );
      
      if (response.ok) {
        const result = await response.json();
        results.successful.push({
          booking_id: bookingId,
          booking_code: result.data.booking_code,
          deleted_at: result.data.deleted_at
        });
        results.summary.deleted++;
      } else {
        const error = await response.json();
        results.failed.push({
          booking_id: bookingId,
          error: error.error.message,
          code: error.error.code
        });
        results.summary.errors++;
      }
      
    } catch (error) {
      results.failed.push({
        booking_id: bookingId,
        error: error.message,
        code: 'network_error'
      });
      results.summary.errors++;
    }
    
    // Small pause to avoid rate limiting
    await new Promise(resolve => setTimeout(resolve, 100));
  }
  
  return results;
}

// Usage
const bookingIds = [123, 124, 125, 126];
const results = await bulkDeleteBookings(bookingIds, 'Obsolete data cleanup');

console.log(`Deleted: ${results.summary.deleted}/${results.summary.total}`);
if (results.failed.length > 0) {
  console.log('Errors:', results.failed);
}
```

### 3. Deletion with User Confirmation

```javascript
// Function with interactive confirmation
async function deleteBookingWithConfirmation(bookingId) {
  try {
    // Get booking details
    const response = await fetch(`/wp-json/latepoint-api/v1/bookings/${bookingId}`, {
      headers: { 'X-API-Key': 'your_api_key' }
    });
    
    const booking = await response.json();
    const data = booking.data;
    
    // Show booking information
    const confirmMessage = `
Are you sure you want to delete this booking?

Code: ${data.booking_code}
Customer: ${data.customer.first_name} ${data.customer.last_name}
Service: ${data.service.name}
Date: ${data.start_date} ${data.start_time}
Status: ${data.status}

This action cannot be undone.
    `;
    
    if (confirm(confirmMessage)) {
      const reason = prompt('Reason for deletion (optional):');
      
      const params = new URLSearchParams({
        force: 'true',
        notify_customer: 'true'
      });
      
      if (reason) params.append('reason', reason);
      
      const deleteResponse = await fetch(
        `/wp-json/latepoint-api/v1/bookings/${bookingId}?${params}`,
        {
          method: 'DELETE',
          headers: { 'X-API-Key': 'your_api_key' }
        }
      );
      
      if (deleteResponse.ok) {
        const result = await deleteResponse.json();
        alert(`Booking ${result.data.booking_code} deleted successfully`);
        return result;
      } else {
        const error = await deleteResponse.json();
        alert(`Error: ${error.error.message}`);
        throw new Error(error.error.message);
      }
    } else {
      console.log('Deletion cancelled by user');
      return null;
    }
    
  } catch (error) {
    console.error('Error:', error.message);
    alert(`Error deleting booking: ${error.message}`);
    throw error;
  }
}
```

### 4. Cleanup of Old Bookings

```javascript
// Function to automatically clean up old bookings
async function cleanupOldBookings(daysOld = 365, status = 'cancelled') {
  try {
    // Calculate cutoff date
    const cutoffDate = new Date();
    cutoffDate.setDate(cutoffDate.getDate() - daysOld);
    const cutoffDateStr = cutoffDate.toISOString().split('T')[0];
    
    // Search for old bookings
    const searchParams = new URLSearchParams({
      status: status,
      end_date_before: cutoffDateStr,
      per_page: 100
    });
    
    const response = await fetch(
      `/wp-json/latepoint-api/v1/bookings?${searchParams}`,
      {
        headers: { 'X-API-Key': 'your_api_key' }
      }
    );
    
    const bookings = await response.json();
    
    if (bookings.data.length === 0) {
      console.log('No old bookings found to delete');
      return { deleted: 0, errors: 0 };
    }
    
    console.log(`Found ${bookings.data.length} bookings to delete`);
    
    // Delete bookings in batches
    const bookingIds = bookings.data.map(booking => booking.id);
    const results = await bulkDeleteBookings(
      bookingIds, 
      `Automatic cleanup - ${status} bookings older than ${daysOld} days`
    );
    
    console.log(`Cleanup completed: ${results.summary.deleted} deleted, ${results.summary.errors} errors`);
    
    return results.summary;
    
  } catch (error) {
    console.error('Error in automatic cleanup:', error.message);
    throw error;
  }
}

// Schedule monthly cleanup
setInterval(() => {
  cleanupOldBookings(365, 'cancelled')
    .then(summary => {
      console.log('Automatic cleanup completed:', summary);
    })
    .catch(error => {
      console.error('Error in automatic cleanup:', error);
    });
}, 30 * 24 * 60 * 60 * 1000); // 30 days
```

## Important Notes

<Note>
  **Deletion vs Cancellation**: In most cases, it's better to cancel a booking (change status to `cancelled`) than to delete it permanently.
</Note>

<Warning>
  **Irrecoverable Data**: Once deleted, all booking information is permanently lost. Make sure you have backups if necessary.
</Warning>

<Tip>
  **Auditing**: Always provide a reason for deletion. This helps with auditing and change tracking.
</Tip>

<Info>
  **Notifications**: Use `notify_customer=true` to inform the customer about the cancellation before deleting the booking.
</Info>
