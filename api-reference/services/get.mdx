---
title: "Get Service"
api: "GET /wp-json/latepoint-api/v1/services/{id}"
description: "Retrieve a specific service by ID with optional related data."
---

## Path Parameters

<ParamField path="id" type="integer" required>
  The unique identifier of the service
</ParamField>

## Query Parameters

<ParamField query="include" type="string">
  Include related data (comma-separated: category, agents, locations)
</ParamField>

## Example Requests

### Basic Request
```bash
GET /wp-json/latepoint-api/v1/services/1
X-API-Key: YOUR_API_KEY
```

### Include Related Data
```bash
GET /wp-json/latepoint-api/v1/services/1?include=category,agents
X-API-Key: YOUR_API_KEY
```
