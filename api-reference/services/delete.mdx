---
title: "Delete Service"
api: "DELETE /wp-json/latepoint-api/v1/services/{id}"
description: "Delete a service. Cannot delete services with associated bookings."
---

## Example Request

```bash
DELETE /wp-json/latepoint-api/v1/services/1
X-API-Key: YOUR_API_KEY
```

## Response Example

```json
{
  "success": true,
  "message": "Service deleted successfully"
}
```
