---
title: "Export Orders"
api: "GET https://your-site.com/wp-json/latepoint-api/v1/orders/export"
description: "Download a CSV file containing order (transaction) data."
---

### Response
Returns a CSV file download containing order records.

### CSV Columns
| Column | Description |
| :--- | :--- |
| ID | Order ID |
| Token | Payment Token |
| Booking ID | Associated Booking ID |
| Customer | Customer Name |
| Processor | Payment Processor (Stripe, PayPal, etc.) |
| Method | Payment Method |
| Amount | Transaction Amount |
| Status | Payment Status |
| Type | Transaction Type |
| Date | Date of Transaction |
